# Mise Task Contract

Use `mise run <task>` as the command interface.

Required tasks:

- `docs:verify`
- `docs:build`
- `verify`

Optional tasks are capability-based and may include:
`bootstrap`, `dev`, `fmt`, `lint`, `test`, `build`, `smoke`, `clean`.
